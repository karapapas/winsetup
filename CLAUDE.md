General rules for the project.

## Regarding README and other documentation files.
- Do not use icons on Readme files.
- Do not use emojis on Readme files.

## Regarding code quality and readability.
- Always try to achieve the acceptance criteria of the requested changes of the prompt by making the minimum possible changes. 

## Regarding actions prior to submitting a response.
- Make sure to follow these rules, before submit to me a response that affects any file.
- If you are going to make changes to code and you have detected a test suite or even some individual test cases, always run them before proceeding with code changes and before presenting an answer, if they don't pass mention it in the answer.
